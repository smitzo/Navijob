# NaviJob images

Open [index.html](index.html) in Chrome or another browser to see all images in one gallery. Click an image to open its original file in a new tab.

From the NaviJob project folder:

```bash
xdg-open assets/index.html
```

You can also double-click `assets/index.html` in your file manager. The gallery works offline and does not need the app server.

## Folder layout

| Folder | Contents |
| --- | --- |
| [b-colours/](b-colours/) | Current B1, B2 and B3 colour options |
| [round-02/](round-02/) | Gallery-led concepts, including selected direction B |
| [round-01/](round-01/) | Earlier rejected concepts, retained as history |
| [references/](references/) | Attributed third-party study captures |

All future design images belong in this project-root `assets/` folder, using clearly named subfolders and versioned filenames. Save generated outputs here before referencing them in documentation. Keep exact prompts, manifests and design decisions in [designs/](../designs/README.md); add new previews to [the gallery](index.html).

Third-party captures remain study references, with attribution in [the source record](../designs/round-02/REFERENCES.md). B / Open Road is selected; B1 / Sage & Forest is the selected palette.
