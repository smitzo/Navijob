## Why

Existing demo routes and local demo sessions must become a consistent, access-controlled product foundation.

## What Changes

- Implement the selected visual tokens, layouts and reusable controls.
- Build real account, email confirmation and recovery journeys.
- Enforce candidate, recruiter and operator permissions on the server; separate demo data.

Dependencies: M01. Non-goals: AI features, external browser automation, job-marketplace scale, billing or deployment.

## Capabilities

### New Capabilities

- `platform-foundation`: Platform, design system and accounts.

### Modified Capabilities

None. Existing application behavior must be audited rather than presumed production-ready.

## Impact

frontend app/layout/components, backend accounts/API authorization, authentication integration. This is a proposed milestone; implementation tasks remain open.
