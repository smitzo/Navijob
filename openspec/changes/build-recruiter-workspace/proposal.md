## Why

Employers need an understandable workflow from creating a role to reviewing applications and keeping candidates informed.

## What Changes

- Build company setup and recruiter-authority requests.
- Provide role draft/edit, publication review and close/archive behavior.
- Build applicant lists, snapshot review, private notes and allowed stage transitions.

Dependencies: M04, M05. Non-goals: Bulk unsolicited outreach, AI screening, external ATS replacement, enterprise SSO or automated billing.

## Capabilities

### New Capabilities

- `recruiter-workspace`: Recruiter roles and applicant review.

### Modified Capabilities

None. Existing application behavior must be audited rather than presumed production-ready.

## Impact

backend companies/recruiters/jobs permissions, recruiter setup/job/applicant UI. This is a proposed milestone; implementation tasks remain open.
