## Why

Candidates need reusable career information and inspectable project context before applications can avoid repeated entry.

## What Changes

- Build private career profile editing and useful completion guidance.
- Support four private resume uploads with clear named versions and a selected primary resume.
- Add project contribution, maturity, stack and optional evidence links; make public sharing an explicit choice.

Dependencies: M02. Non-goals: AI resume generation, opaque ATS scores, GitHub skill rankings or broad public recruiter search.

## Capabilities

### New Capabilities

- `candidate-career-profiles`: Candidate profiles, resumes and projects.

### Modified Capabilities

None. Existing application behavior must be audited rather than presumed production-ready.

## Impact

backend accounts/resumes, file storage, frontend profile/resume/project routes. This is a proposed milestone; implementation tasks remain open.
