## Context

A small real cohort should test repeated candidate utility and employer value before paid plans or broader automation. This milestone depends on M07. Read PRODUCT_PLAN.md, designs/DESIGN_BRIEF.md and openspec/BOARD.md before implementation. Current work produces plans only.

## Goals / Non-Goals

**Goals:**

- Define a small candidate cohort and checked employer roles with explicit consent.
- Operate introductions and application review with named contacts and a support process.
- Record repeat use, completion, qualified responses and actual time/cost; decide the next scope.

**Non-Goals:** Invented hiring metrics, guaranteed placements, automatic subscriptions, MNC procurement or external contact without authorization.

## Decisions

- Use proposed initial learning hurdles of 20 candidates and two real employer roles, adjusted to observed capacity.
- Prefer qualified responses and repeat behavior over registration or application volume.
- Treat launch, recruitment outreach and paid-service activation as explicit later operational actions.

## Risks / Trade-offs

- A community count is mistaken for an active suitable pool; count eligible and opted-in candidates separately.
- A small sample is treated as statistical proof; report denominators, observation periods and limitations.
