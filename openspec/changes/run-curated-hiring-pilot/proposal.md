## Why

A small real cohort should test repeated candidate utility and employer value before paid plans or broader automation.

## What Changes

- Define a small candidate cohort and checked employer roles with explicit consent.
- Operate introductions and application review with named contacts and a support process.
- Record repeat use, completion, qualified responses and actual time/cost; decide the next scope.

Dependencies: M07. Non-goals: Invented hiring metrics, guaranteed placements, automatic subscriptions, MNC procurement or external contact without authorization.

## Capabilities

### New Capabilities

- `curated-hiring-pilot`: Run a small curated hiring pilot.

### Modified Capabilities

None. Existing application behavior must be audited rather than presumed production-ready.

## Impact

pilot operating record, product analytics definitions, support and feedback. This is a proposed milestone; implementation tasks remain open.
